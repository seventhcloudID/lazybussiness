pertanyaan

Yang biasanya ditanya duluan.

Kenapa harus pakai API key sendiri?

Biar kamu nggak bayar dua kali. Langganan cuma buat dashboard; token Gemini/OpenAI tetap lewat key workspace kamu (BYOK).

Gimana cara daftar?

Tidak ada signup publik. Klik Minta akses, admin buatkan tenant + login. Habis itu masuk lewat /app.

Satu workspace itu apa?

Satu workspace bisa banyak akun brand (mis. @bimosept dan @tigaawanstudio). Key Gemini/OpenAI dipakai bersama di level workspace.

Thumbnail wajib OpenAI?

Opsional. Tanpa OpenAI, generate utas, Lazy, carousel, balasan, dan insight tetap jalan dengan Gemini.

TikTok dan X langsung connect?

Lewat Buffer: isi Buffer key per akun brand, pilih channel TikTok/X, lalu push dari dashboard.

Kalau kuota Gemini habis?

Generate AI berhenti sampai kuota key-mu pulih atau kamu ganti/tambah key di Akun → API keys. Kuota tampil di sidebar dashboard.

Konten seminggu bisa kelar tanpa nulis dari nol.

Minta akses, tempel key Gemini, connect Threads/IG — utas pertama biasanya sudah jadi sebelum kopi dingin.
