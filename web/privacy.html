Kebijakan Privasi

Terakhir diperbarui: 5 Agustus 2026 · Berlaku untuk layanan malesngonten di flowa.tigaawan.com

Kebijakan ini menjelaskan bagaimana malesngonten (“kami”, “layanan”) mengumpulkan, memakai, menyimpan, dan melindungi data saat Anda menggunakan dashboard konten Threads & Instagram, termasuk login Meta (Threads/Instagram), penjadwalan Lazy, dan fitur AI.

1. Pengelola data

Layanan dioperasikan untuk produk malesngonten. Kontak privasi: rootedblack@gmail.com.

2. Data yang kami kumpulkan

  • Akun dashboard — username login, hash kata sandi, sesi, dan peran (mis. admin/tenant).
  • Akun sosial (Threads / Instagram) — token akses (termasuk long-lived), ID/username profil, dan metadata akun yang diperlukan untuk publish, balasan, dan insight.
  • Konten yang Anda buat — draf utas, caption, carousel, jadwal Lazy, media yang diunggah ke layanan, serta log aktivitas terkait.
  • Kunci API pihak ketiga (BYOK) — kunci Gemini/OpenAI yang Anda tempel disimpan agar layanan dapat memanggil AI atas nama Anda.
  • Integrasi opsional — kredensial Buffer (atau sejenis) jika Anda menghubungkan TikTok/X lewat Buffer.
  • Data teknis — log server terbatas (waktu, endpoint, error) untuk keamanan dan troubleshooting.

3. Cara kami mengumpulkan data

  • Langsung dari Anda (form login, pengaturan akun, unggahan konten, tempel token/key).
  • Melalui OAuth Meta saat Anda menekan “Login dengan Threads” atau “Login dengan Instagram” dan memberikan izin.
  • Dari API Meta / Buffer / penyedia AI saat fitur yang Anda aktifkan dijalankan.

4. Tujuan penggunaan

  • Menyediakan dashboard: generate konten, publish, balasan, insight, dan penjadwalan.
  • Menghubungkan dan menjaga sesi ke akun Threads/Instagram Anda.
  • Memproses permintaan AI dengan kunci yang Anda sediakan.
  • Keamanan, pencegahan penyalahgunaan, dan pemeliharaan layanan.
  • Memenuhi permintaan penghapusan data dari Meta atau dari Anda.

Kami tidak menjual data pribadi Anda. Kami tidak memakai konten Anda untuk melatih model AI milik kami sendiri.

5. Berbagi data dengan pihak ketiga

Data dapat dikirim ke pihak ketiga hanya sejauh diperlukan agar fitur berjalan:

  • Meta (Threads / Instagram) — publish, baca profil/insight, dan alur OAuth sesuai izin yang Anda berikan.
  • Google (Gemini) / OpenAI — jika Anda mengaktifkan fitur AI dan menyediakan API key.
  • Buffer — jika Anda menghubungkan kanal TikTok/X lewat Buffer.
  • Hosting / infrastruktur — server tempat layanan dijalankan (mis. VPS yang menghosting flowa.tigaawan.com).

Kebijakan privasi pihak ketiga tersebut berlaku untuk pemrosesan di sisi mereka.

6. Penyimpanan & keamanan

  • Token, kunci API, dan data workspace disimpan di server layanan (penyimpanan lokal terenkripsi sesi/kredensial sesuai konfigurasi server).
  • Akses dashboard dilindungi autentikasi.
  • Kami menerapkan upaya wajar untuk melindungi data, namun tidak ada transmisi internet yang 100% aman.

7. Retensi data

Data disimpan selama akun Anda aktif atau selama diperlukan untuk menyediakan layanan. Token Meta dapat kedaluwarsa sesuai kebijakan Meta; Anda dapat memutuskan koneksi kapan saja dari halaman Akun.

8. Hak Anda & penghapusan data

  • Anda dapat menghapus token Threads/Instagram, kunci API, atau akun brand dari dashboard.
  • Anda dapat meminta penghapusan data dengan menghubungi rootedblack@gmail.com.
  • Jika Anda mencabut aplikasi lewat pengaturan Meta, kami dapat menerima callback deauthorize / permintaan penghapusan data dan memprosesnya.
  • Status permintaan penghapusan lewat Meta dapat dilihat di URL konfirmasi yang dikembalikan sistem (halaman status hapus data).

9. Cookie & sesi

Kami memakai cookie/sesi yang diperlukan untuk login dashboard dan keamanan sesi. Kami tidak memakai cookie iklan pihak ketiga di halaman kebijakan ini.

10. Anak di bawah umur

Layanan ditujukan untuk pengguna bisnis/kreator dewasa. Kami tidak sengaja mengumpulkan data anak di bawah 13 tahun (atau usia minimum yang berlaku di yurisdiksi Anda).

11. Perubahan kebijakan

Kami dapat memperbarui kebijakan ini. Tanggal “Terakhir diperbarui” akan diubah. Penggunaan layanan setelah perubahan berarti Anda memahami versi terbaru.
